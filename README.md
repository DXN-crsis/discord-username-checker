## Overview

Checks username availability through a responsive Qt interface. The engine uses
an AIMD-style throttle to stay within rate limits, rotates request fingerprints,
and expands the candidate set on the fly.

## Getting started

```bash
pip install -r requirements.txt
python main.py
```

Convenience launchers `run.sh` and `run.bat` are included.
